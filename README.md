# Радар робототехники

Собирает новости о роботах из RSS, Google News и Telegram, с помощью Claude превращает их в базу
**компаний, решений и событий** (раунды, продукты, контракты, пилоты, метрики) и показывает
на одной странице с фильтрами по рубрикам, России и миру и «нашим нишам».

```
каждые 4 часа (GitHub Actions)
  сбор ──► очередь ──► Claude Haiku: «это про рынок роботов? кто, что, сколько» ──► база (data/*.json)
                                                                                    │
раз в неделю                                                                         ▼
  Claude Sonnet + веб-поиск: сайт, раунды, выручка, парк роботов ──► карточки   site/data/radar.json
  Claude Sonnet: дайджест недели ──► страница и Telegram-чат                        │
                                                                                    ▼
                                                              страница (ваш сервер или GitHub Pages)
```

База — обычные текстовые файлы в `data/`. Их видно в истории git, можно поправить руками,
а при переезде на свой сервер — загрузить в Postgres.

## Запуск

1. **Репозиторий.** Создайте приватный репозиторий на GitHub и залейте в него содержимое этой папки.
2. **Ключ.** Settings → Secrets and variables → Actions → New repository secret:
   `ANTHROPIC_API_KEY`. Про доступность API см. раздел «Что важно знать».
3. **Первый прогон.** Actions → «Радар» → Run workflow → `run`. Через несколько минут в репозитории
   появится коммит `radar: run …` с обновлёнными `data/` и `site/data/radar.json`.
   Дальше всё идёт по расписанию.
4. **Страница.** Выберите один из вариантов ниже.

### Страница на своём сервере (для команды, с паролем)

Сервер только раздаёт готовые файлы: Python и ключи на нём не нужны.

```bash
sudo apt install -y nginx git apache2-utils
ssh-keygen -t ed25519 -f ~/.ssh/radar_deploy -N ""          # ключ только для чтения репозитория
cat ~/.ssh/radar_deploy.pub                                 # → GitHub: Settings → Deploy keys → Add
printf 'Host github.com\n  IdentityFile ~/.ssh/radar_deploy\n  IdentitiesOnly yes\n' >> ~/.ssh/config

sudo mkdir -p /opt/radar && sudo chown "$USER" /opt/radar
git clone git@github.com:ВАШ_АККАУНТ/robotics-radar.git /opt/radar
(crontab -l 2>/dev/null; echo '*/15 * * * * /opt/radar/deploy/radar-pull.sh >> /tmp/radar-pull.log 2>&1') | crontab -

sudo cp /opt/radar/deploy/nginx-radar.conf /etc/nginx/sites-available/radar   # поправьте server_name
sudo ln -s /etc/nginx/sites-available/radar /etc/nginx/sites-enabled/radar
sudo htpasswd -c /etc/nginx/radar.htpasswd team                                # пароль для команды
sudo nginx -t && sudo systemctl reload nginx
```

### Страница на GitHub Pages

Проще, но страница открыта всем, у кого есть ссылка, а на бесплатном тарифе GitHub Pages работает
только из публичного репозитория. Settings → Pages → Source: GitHub Actions, затем
Settings → Secrets and variables → Actions → Variables → `DEPLOY_PAGES` = `true`.

## Настройка

| Что | Где |
|---|---|
| Источники: RSS, запросы Google News, Telegram-каналы, ключевые слова | `config/sources.yaml` |
| Рубрики, типы событий, «наши ниши» | `config/taxonomy.yaml` |
| Стартовый список компаний | `config/seed_companies.yaml` |
| Ручные правки карточек (побеждают автоматику), скрытие и склейка дублей | `config/overrides.yaml` |
| Правила «что берём и что не берём» для модели | `radar/extract.py`, блок `RELEVANCE` |

**Telegram.** Публичные каналы читаются через веб-превью `t.me/s/имя`: аккаунт, сессии и ключи
не нужны. Допишите имена каналов в `config/sources.yaml`; каналам про беспилотники ставьте
`filter: true`, иначе в очередь попадёт военная хроника. Закрытые каналы так не читаются —
для них понадобится Telethon и отдельный аккаунт.

**Уведомления.** Добавьте секреты `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` — бот будет присылать
в чат команды важные события (важность от 4 и всё из «наших ниш») и недельный дайджест.

**Переменные** (Settings → Variables, все необязательные): `RADAR_MODEL_FAST` (по умолчанию
`claude-haiku-5-5`), `RADAR_MODEL_SMART` (`claude-sonnet-5-5`), `RADAR_ENRICH_LIMIT` (12 компаний
в неделю), `RADAR_MAX_ITEMS_PER_RUN` (400 новостей за прогон).

## Команды

```bash
pip install -r requirements.txt
python -m radar check      # проверить, что источники отвечают (ничего не пишет)
python -m radar run        # сбор → разбор → страница
python -m radar weekly     # обогащение карточек + дайджест
python -m radar review     # пересмотреть записанные события по текущим правилам релевантности
python -m pytest -q        # тесты, без сети и ключей
python -m http.server 8000 --directory site    # посмотреть страницу локально
```

## Сколько стоит

Оценка, не измерение: разбор новостей на Claude Haiku 5.5 ($0,10 / $0,50 за млн токенов) —
единицы долларов в месяц; обогащение 12 карточек в неделю на Sonnet 5.5 с веб-поиском
($10 за 1000 поисков) — около $2 в неделю. Итого порядка $10–15 в месяц. Фактический расход
за 30 дней показан в подвале страницы. GitHub Actions: около 400–500 минут в месяц
из 2000 бесплатных для приватных репозиториев.

## Что важно знать

- **Регион Claude API.** Россия не входит в список стран, где Anthropic предоставляет API, и политика
  учитывает местонахождение и юрлицо пользователя: <https://www.anthropic.com/supported-countries>.
  Проверьте, что ваш аккаунт API под неё подходит. Если нет — радар работает с любой моделью
  с OpenAI-совместимым API: задайте `OPENAI_COMPAT_BASE_URL`, `OPENAI_COMPAT_MODEL`
  и секрет `OPENAI_COMPAT_API_KEY`. Разбор новостей и дайджест будут работать, обогащение
  карточек через веб-поиск — нет (это функция Claude API).
- **Что проверено.** Сбор из всех источников, склейка компаний, сборка страницы и сама страница
  проверены вживую 16.11.2026. Запросы к Claude API проверены только тестами на подставном клиенте:
  ключа при разработке не было. Если API отклонит structured outputs, код сам перейдёт на JSON в тексте
  и напишет об этом в журнале прогона.
- **Первые события в базе** (28 штук от 10–16 ноября 2026) разобраны вручную из реально собранных
  новостей, чтобы страница не была пустой. Со следующего прогона разбор делает модель.
- **Стартовый список компаний** составлен по памяти модели и содержит только название, страну
  и рубрику. Проверяет и дополняет его еженедельное обогащение.
- **Цифры.** Выручку и размер парка частные компании раскрывают редко. В карточку попадает только то,
  у чего есть ссылка на источник; суммы пересчитываются в доллары по курсу на день прогона.
- **Google News** отдаёт только заголовки и ссылки-редиректы, поэтому подробности по таким новостям
  беднее, чем по RSS и Telegram.

## Что можно добавить дальше

- Выручка российских компаний из открытой бухгалтерской отчётности (ГИР БО) по ИНН. Скорее всего,
  этот шаг придётся запускать с российского сервера: доступность сервиса с зарубежных адресов не проверялась.
- Закрытые Telegram-каналы через Telethon.
- Платные базы сделок (Crunchbase, Dealroom) — если появится доступ к их API.
- Переезд базы в Postgres и API для команды, когда текстовых файлов станет мало.
